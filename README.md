# Algoritmi elementari în C++

Colecție de algoritmi elementari de bază, fiecare într-un fișier `.cpp` separat.

| Fișier | Ce face |
|---|---|
| `CMMDC.cpp` | Cel mai mare divizor comun a două numere |
| `CMMMC.cpp` | Cel mai mic multiplu comun a două numere |
| `Cel mai mare numar fibonacci mai mic sau egal cu n.cpp` | Cel mai mare termen Fibonacci ≤ n |
| `Cifra de control a lui n.cpp` | Cifra de control (suma repetată a cifrelor) |
| `Descompunerea in factori primi...cpp` | Descompunerea lui n în factori primi |
| `Determinarea divizorilor proprii ai lui n.cpp` | Divizorii proprii ai lui n |
| `Numarul de divizori a lui n.cpp` | Numărul de divizori ai lui n |
| `Ultima cifra a lui x la puterea y.cpp` | Ultima cifră a lui x^y |
| `Verificare daca un nr e prim.cpp` | Testul de primalitate |
| `Algoritmi Cifre/` | Algoritmi pe cifrele unui număr |

## Compilare

```bash
g++ -std=c++17 -O2 "CMMDC.cpp" -o cmmdc
./cmmdc
```
